# Gen5W 실차 검증 절차

Gen5W 및 HMG-API 환경을 위한 검증 절차입니다. 주차 중 설치와 화면 조작을 진행하고 주행 중 기록은 동승자가 담당합니다.

## 진단 먼저

1. HMG-API Mod Manager 설치 및 버전을 확인합니다. PC에서 기존 ADB 연결을 이용해 `adb shell hmgapid version`으로 데몬 버전도 확인할 수 있습니다.
2. Manager의 v1.0.2 표준 설치 경로는 기존 업데이트 매체의 `HMGAPI/updates/`에 진단 ZIP을 놓고 `Check USB updates → Install`을 누르는 방식입니다. ZIP은 압축을 푼 상태로 설치하지 않습니다. PC에서 이미 승인된 HMG-API 관리자 ADB 경로를 쓰는 환경에서는 ZIP을 스테이징하고 공식 `hmgapid engine install <zip-path>` 경로를 사용합니다. 일반 ADB shell은 관리자 명령을 거부할 수 있습니다. 진단과 미터기 자체의 운영에 별도 USB 장치는 필요 없습니다.
3. 설치 확인에서 빌드의 작성자 및 Mod 이름을 확인합니다. `Mods` 탭에서 활성 상태를 확인하고 `Apply changes`를 실행합니다. 전체 앱 메뉴에서 **Gen5W 차량 데이터 진단**을 실행합니다. 메뉴 항목이 생성되지 않으면 기존 ADB에서 다음으로 Activity만 실행합니다.

   ```powershell
   adb shell am start -n dev.gen5w.taxi.diag/.Launcher
   ```

4. 주차 상태에서 30초 이상 0 km/h이며 적분 거리 변화가 없는지 기록합니다. `0.00`은 유효한 정차입니다. `–`는 미응답입니다. 버전은 확인되지만 속도가 계속 `–`이면 HMG-API의 Car Report에서 맵 상태를 확인하고 진단 결과를 보관합니다.
5. 안전한 경로에서 동승자가 속도, 요청 주기, 최대 지연, 주행계 변경 단위와 갱신 시점을 기록합니다. 계기판 또는 독립적인 비교 거리와 적분 거리를 대조합니다. GPS가 끊겨도 속도가 유효하면 적분이 이어지는지 봅니다.
6. **로그 내보내기**를 눌러 화면에 나오는 경로를 확인합니다. 예시는 아래와 같습니다. 로그는 최근 최대 300행, 1초마다 1행이며 위도·경도는 화면에만 표시합니다.

   ```powershell
   adb pull /sdcard/Android/data/dev.gen5w.taxi.diag/files/diagnostic.csv .
   ```

## 미터기 검증

| 항목 | 수행과 기대값 |
| --- | --- |
| 정차·저속 | 유효한 0 km/h에서 거리는 0을 유지. 주행 버튼으로 시작하거나 주행 후 정차하면 저속 시간이 누적. 울산에서 15 km/h 미만 시 시간 등가 진행을 확인 |
| 정상 주행 | 3 km/h 초과 출발 시 원본 자동 시작. 주행 거리와 비교 기준을 기록 |
| 수신 중단 | 정차 후 Mod 비활성화 등을 이용해 접근 실패를 관찰. 속도·시간·거리 계산 중단과 복구 첫 샘플에서 점프가 없는지 확인. 관리자 조치로 앱 자체가 닫히면 재시작 후 초기화로 기록 |
| GPS 수신 중단 | 지하 또는 GPS 비활성화에서 거리 적분 유지 및 마지막 요금 지역 표시. 수동 울산 선택과 GPS 자동 선택 복귀 확인 |
| 할증 | 호스트 테스트에서 야간 경계를 검증. 차에서는 자연 시각 경계를 관찰하고 시작·추가 요금 동작을 구분 |
| 말 | 0.1.1 미터기에서 정차 프레임, 속도 비례 가속, 감속 후 정지 동작 확인 |
| 시동·복귀 | 홈 화면에서도 수집되는지와 미터기 복귀 시 기존 요금이 이어지는지 확인. 프로세스 재실행과 시동 사이클에서 운행 초기화 및 선택 지역 복원 |
| 업데이트 | 동일 작성자 및 APK 키로 versionName/Mod version과 versionCode를 올린 시험 빌드로 갱신. 설정 유지 확인 |
| 제거 | Manager에서 두 Mod를 하나씩 제거. 앱 메뉴와 패키지 제거를 확인하고 순정 앱 동작 확인 |

실차 기록에는 펌웨어, 데몬 버전, 맵 상태, 주차/주행 여부, 속도 범위, 요청 주기, 주행계 분해능, GPS 정확도, 적분 오차와 설치·제거 결과를 남깁니다. 이 절차서의 항목은 실제 결과가 수신되기 전까지 미검증입니다.
